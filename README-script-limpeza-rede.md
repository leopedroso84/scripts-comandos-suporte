# Script de Limpeza de Rede no Windows

Arquivo: `script-limpeza-rede-windows.bat`

## O que o script faz

- Limpa o cache DNS.
- Libera o IP atual.
- Renova o IP.
- Testa conexão com IP externo.
- Testa resolução de nome.

## Como usar

1. Baixar o arquivo `.bat`.
2. Executar como administrador, se necessário.
3. Acompanhar os resultados na tela.
4. Registrar no chamado se houve falha em alguma etapa.

## Atenção

Este script é simples e genérico. Deve ser usado apenas em ambientes onde o procedimento é permitido.
