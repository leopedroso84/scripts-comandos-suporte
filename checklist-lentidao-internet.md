# Checklist de Lentidão na Internet

## 1. Identificar o cenário

- A lentidão ocorre em todos os dispositivos?
- O problema acontece via Wi-Fi, cabo ou ambos?
- A lentidão é constante ou em horários específicos?
- O usuário está próximo ou distante do roteador?
- Há muitos dispositivos conectados?

## 2. Testes iniciais

- Reiniciar navegador ou aplicativo.
- Testar outro site.
- Testar outro dispositivo.
- Testar conexão via cabo, se possível.
- Aproximar do roteador para teste Wi-Fi.

## 3. Comandos úteis

```cmd
ping 8.8.8.8
ping google.com
tracert google.com
ipconfig /flushdns
```

## 4. Verificações de Wi-Fi

- Verificar intensidade de sinal.
- Conferir distância do roteador.
- Avaliar interferências.
- Testar rede 2.4 GHz e 5 GHz.
- Verificar posicionamento de repetidores ou pontos Mesh.

## 5. Possíveis causas

- Sinal Wi-Fi fraco.
- Interferência.
- Equipamento sobrecarregado.
- Problema no provedor.
- DNS instável.
- Dispositivo com problema local.
- Uso excessivo de banda.

## 6. Registro no chamado

Registrar:
- Resultado dos testes.
- Velocidade contratada, se informada.
- Velocidade medida, se testada.
- Tipo de conexão usada no teste.
- Equipamentos envolvidos.
- Próximo encaminhamento.
