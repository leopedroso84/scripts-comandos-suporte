# Comandos de Rede no Windows

## Ver informações de IP

```cmd
ipconfig
```

## Ver informações completas de rede

```cmd
ipconfig /all
```

## Liberar IP atual

```cmd
ipconfig /release
```

## Renovar IP

```cmd
ipconfig /renew
```

## Limpar cache DNS

```cmd
ipconfig /flushdns
```

## Testar conexão com IP externo

```cmd
ping 8.8.8.8
```

## Testar resolução de DNS

```cmd
ping google.com
```

## Ver rota até um destino

```cmd
tracert google.com
```

## Consultar DNS

```cmd
nslookup google.com
```

## Ver conexões ativas

```cmd
netstat -ano
```

## Ver tabela de rotas

```cmd
route print
```
