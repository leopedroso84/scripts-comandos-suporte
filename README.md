# Scripts e Comandos para Suporte Técnico

Repositório com comandos úteis, exemplos simples e checklists para diagnóstico em suporte técnico, redes, Windows e conectividade.

## Objetivo

Organizar comandos e procedimentos básicos usados em atendimentos de suporte técnico, Help Desk, Service Desk e infraestrutura de TI.

## Conteúdos

- Comandos de rede no Windows
- Diagnóstico de DNS e conectividade
- Limpeza de cache DNS
- Testes de ping e rota
- Checklist de lentidão
- Procedimentos básicos para suporte remoto

## Áreas relacionadas

- Suporte Técnico
- Help Desk
- Service Desk
- Redes
- Infraestrutura de TI
- Troubleshooting

## Observação

Os comandos aqui são exemplos genéricos para estudo e portfólio técnico. Devem ser usados com responsabilidade e adaptados conforme o ambiente.
